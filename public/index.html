A tiny REST API that capitalizes strings 29 ways. Type something, click a card to copy, or just hit the URL. Powered by capstring.

Endpoints
  • GET /:style/:text or /:style/:text.json|txt|html|xml|yaml|csv|jsonp
  • GET /chain/:style+:style/:text apply several styles in order
  • POST /batch {"inputs":[...],"style":"kebab"} up to 100 strings
  • GET /spell/:text spell-corrected text, no API key
  • GET /badge/:style/:text SVG badge for your README
  • GET /count/:text words and characters, GET /lorem/:n placeholder text
  • GET /styles every style name
Self-host with npx @brianfunk/capita. Source on GitHub. MIT.
